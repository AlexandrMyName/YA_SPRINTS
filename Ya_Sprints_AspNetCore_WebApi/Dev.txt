
Создадим топик командой внутри контейнера:

docker exec -it <container_name> kafka-topics \
  --bootstrap-server localhost:9092 \
  --create \
  --topic orders \
  --partitions 3 \
  --replication-factor 1 

  Обязательные параметры:
--bootstrap-server — адрес брокера для первоначального подключения;
--create — создать топик;
--topic — имя топика;
--partitions — число партиций;
--replication-factor — фактор репликации;  


Просмотр топиков
Посмотреть список всех топиков:

docker exec -it <container_name> kafka-topics \
  --bootstrap-server localhost:9092 \
  --list 
Посмотреть детали конкретного топика:

docker exec -it <container_name> kafka-topics \
  --bootstrap-server localhost:9092 \
  --describe \
  --topic orders 
Вывод команды --describe:
Topic: orders   PartitionCount: 3   ReplicationFactor: 1
  Topic: orders   Partition: 0   Leader: 1   Replicas: 1   Isr: 1
  Topic: orders   Partition: 1   Leader: 1   Replicas: 1   Isr: 1
  Topic: orders   Partition: 2   Leader: 1   Replicas: 1   Isr: 1
